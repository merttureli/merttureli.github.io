# merttureli.github.io

Personal engineering portfolio — live at [merttureli.github.io](https://merttureli.github.io).

Hand-built static site: HTML + CSS + a few lines of JS. No framework, no build step.

## Structure
```
index.html         one-page overview: projects, experience, skills, about, contact
projects/*.html    one case study per featured project
css/style.css      entire design system (tokens in :root)
js/main.js         scroll reveal + footer year
```

## Preview locally
```
python -m http.server 8137
```
then open http://localhost:8137

Type: Fraunces · Inter · JetBrains Mono (Google Fonts). All text/background pairs WCAG AA.
